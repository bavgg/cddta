================================================================
WHAT IS TRAFFIC ATTRIBUTION?
================================================================

Traffic Attribution = Mapping network packets to specific devices
so you can see "who did what" on the network.

Formula:
  PACKET (MAC + payload)  +  ARP TABLE (MAC → IP + Name)  =  DEVICE ACTIVITY

Without attribution: "Some device sent 50 MB to 142.251.x.x"
With attribution:    "iPhone (.101) sent 50 MB to googlevideo.com (YouTube)"

Note: MAC addresses with prefixes 5e:, 96:, 0e: are randomized (locally administered)

STEP 2: CAPTURE (Must start BEFORE connections)
──────────────────────────────────────────────────
# Start capture FIRST, then generate traffic
sudo tcpdump -i en0 -n -w /tmp/capture.pcap 2>/dev/null &
PID=$!
# ... wait for traffic ...
sleep 30
kill $PID

CRITICAL: Capture must include the TLS HANDSHAKE (Client Hello)
- SNI is only in the first packets of a NEW TLS connection
- If you capture mid-connection, you miss the domain name

STEP 3: ATTRIBUTION (Join packet IP → device name)
──────────────────────────────────────────────────
# Extract TLS SNI (domains visited)
tshark -r /tmp/capture.pcap -Y "tls.handshake.extensions_server_name" \
  -T fields -e ip.src -e tls.handshake.extensions_server_name 2>/dev/null | \
while read ip sni; do
    name=$(grep "^$ip	" /tmp/device_map.txt | cut -f3-)
    echo "$name ($ip) visited $sni"
done

# Extract DNS queries
tshark -r /tmp/capture.pcap -Y "dns" \
  -T fields -e ip.src -e dns.qry.name 2>/dev/null | \
while read ip domain; do
    name=$(grep "^$ip	" /tmp/device_map.txt | cut -f3-)
    echo "$name ($ip) queried $domain"
done

# Bandwidth per device
tshark -r /tmp/capture.pcap -T fields -e ip.src -e frame.len 2>/dev/null | \
awk '{bytes[$1]+=$2} END {for(ip in bytes) print ip, bytes[ip]}' | \
sort -k2 -rn

WHAT YOU CAN SEE vs CANNOT SEE
================================================================

VISIBLE (via attribution):
──────────────────────────
✅ Domain names via TLS SNI: facebook.com, reddit.com, youtube.com
✅ Domain names via DNS queries
✅ Which device (IP → MAC → Name from device map)
✅ Bandwidth per device (bytes sent/received)
✅ Connection count per device
✅ Protocols/ports used
✅ App signatures:
   - Port 62078 = iPhone sync
   - Port 46888 = OPPO OAFP
   - Port 5000/7000 = AirPlay
   - TLS SNI patterns (googlevideo.com = YouTube)

HIDDEN (encrypted inside TLS):
──────────────────────────────
❌ Specific URLs/paths (/user/john, /r/technology)
❌ Search queries
❌ Video titles
❌ POST data (messages, comments, logins)
❌ Cookie values
❌ Page content

MODERN BLOCKERS:
────────────────
⚠️  ECH (Encrypted Client Hello) - hides SNI (iOS 15+, Firefox, Chrome)
⚠️  DoH/DoT (DNS over HTTPS/TLS) - hides DNS queries
⚠️  Private Relay / VPN - hides all domains + IPs

* MITM requires ARP spoofing - disruptive, may be blocked by router (DAI),

#!/bin/bash
# quick_attr.sh - Quick traffic attribution test

IFACE="en0"
DURATION=${1:-15}

# Device map - UPDATE WITH YOUR DEVICES
cat > /tmp/device_map.txt << 'EOF'
192.168.0.1	28:ee:52:f7:74:dc	TP-Link Router
192.168.0.100	5e:ed:d5:5b:8b:0b	MacBook
192.168.0.101	96:2d:fc:a5:07:ff	iPhone
192.168.0.105	0e:70:b3:1a:68:38	OPPO Phone
EOF

echo "Capturing for ${DURATION}s... (generate traffic on devices now!)"
sudo tcpdump -i "$IFACE" -n -w /tmp/quick_attr.pcap 2>/dev/null &
PID=$!
sleep $DURATION
kill $PID 2>/dev/null

echo ""
echo "=== DNS QUERIES ==="
tshark -r /tmp/quick_attr.pcap -Y "dns" -T fields -e ip.src -e dns.qry.name 2>/dev/null | \
awk -F'\t' 'NR==FNR{dev[$1]=$3; next} {name=dev[$1]; if(!name) name="UNKNOWN"; print "  " name " (" $1 ") → " $2}' /tmp/device_map.txt - | sort | uniq -c | sort -rn

echo ""
echo "=== TLS SNI (WEBSITES) ==="
tshark -r /tmp/quick_attr.pcap -Y "tls.handshake.extensions_server_name" -T fields -e ip.src -e tls.handshake.extensions_server_name 2>/dev/null | \
awk -F'\t' 'NR==FNR{dev[$1]=$3; next} {name=dev[$1]; if(!name) name="UNKNOWN"; print "  " name " (" $1 ") → " $2}' /tmp/device_map.txt - | sort | uniq -c | sort -rn

echo ""
echo "=== BANDWIDTH PER DEVICE ==="
tshark -r /tmp/quick_attr.pcap -T fields -e ip.src -e frame.len 2>/dev/null | \
awk 'NR==FNR{dev[$1]=$3; next} {bytes[$1]+=$2} END {for(ip in bytes) {name=dev[ip]; if(!name) name="UNKNOWN"; mb=bytes[ip]/1024/1024; printf "  %s (%s): %.2f MB\n", name, ip, mb}}' /tmp/device_map.txt - | sort -k4 -rn

#!/bin/bash
# continuous_attr.sh - Continuous attribution like NetCut

IFACE="en0"

EOF

echo "Starting continuous attribution (Ctrl+C to stop)..."
echo "Interval: ${INTERVAL}s"
echo ""

while true; do
    TS=$(date "+%H:%M:%S")

    # Capture for interval
    sudo tcpdump -i "$IFACE" -n -w /tmp/continuous.pcap -G $INTERVAL -W 1 2>/dev/null

    echo "=== $TS ==="

    # Quick SNI check
    tshark -r /tmp/continuous.pcap -Y "tls.handshake.extensions_server_name" -T fields -e ip.src -e tls.handshake.extensions_server_name 2>/dev/null | \
    awk -F'\t' 'NR==FNR{dev[$1]=$3; next} {name=dev[$1]; if(!name) name="UNKNOWN"; print "  " name " (" $1 ") → " $2}' /tmp/device_map.txt - | sort | uniq -c | sort -rn | head -10

SCRIPT 3: ARP Scan + Attribution (NetCut-style Loop)
──────────────────────────────────────────────────
#!/bin/bash
# netcut_loop.sh - NetCut-style continuous loop

IFACE="en0"
SUBNET="192.168.0.0/24"

echo "NetCut-style loop started (Ctrl+C to stop)..."

while true; do
    TS=$(date "+%Y-%m-%d %H:%M:%S")

    # 1. ARP Scan (update device map)
    echo "[$TS] ARP Scan..."
    sudo arp-scan --localnet --interface="$IFACE" --quiet 2>/dev/null | \
    grep -E "^[0-9]" | \
    while read ip mac vendor; do
        # Update device map (simplified)
        echo "$ip	$mac	$vendor" >> /tmp/device_map_dynamic.txt
    done

    # 2. TCP SYN Ping (wake sleepers)
    echo "[$TS] TCP SYN Wake..."
    sudo nmap -sn -PS80,443,22,23,21 "$SUBNET" >/dev/null 2>&1

    # 3. Broadcast ping
    ping -c 2 -W 1 192.168.0.255 >/dev/null 2>&1
    sleep 2

    # 4. ARP Follow-up
    echo "[$TS] ARP Follow-up..."
    sudo arp-scan --localnet --interface="$IFACE" --quiet 2>/dev/null | \
    grep -E "^[0-9]" | \
    while read ip mac vendor; do
        echo "$ip	$mac	$vendor" >> /tmp/device_map_dynamic.txt
    done

    # 5. Capture traffic for attribution
    echo "[$TS] Traffic Capture (10s)..."
    sudo tcpdump -i "$IFACE" -n -w /tmp/netcut_loop.pcap -c 200 2>/dev/null

    # 6. Attribution report
    echo "[$TS] Attribution Report:"
    tshark -r /tmp/netcut_loop.pcap -Y "tls.handshake.extensions_server_name" -T fields -e ip.src -e tls.handshake.extensions_server_name 2>/dev/null | \
    sort -u | \
    while read ip sni; do
        name=$(grep "^$ip	" /tmp/device_map_dynamic.txt 2>/dev/null | cut -f3 | head -1)
        [ -z "$name" ] && name="UNKNOWN"
        echo "  $name ($ip) → $sni"
    done

    echo "[$TS] Sleeping 30s..."
    sleep 30
done

================================================================
KEY INSIGHTS FROM TESTING
================================================================

1. CAPTURE TIMING IS CRITICAL
   - Start tcpdump FIRST, then generate traffic
   - TLS Client Hello (with SNI) is in FIRST packets
   - Miss the handshake = miss the domain

2. DEVICE MAP IS THE BRIDGE
   - Without MAC→IP→Name mapping, you only have IPs
   - ARP scan builds this, but misses sleeping/randomized devices
   - Manual entries needed for known devices

3. YOU ONLY SEE YOUR TRAFFIC (without MITM)
   - Switched networks isolate traffic by MAC
   - Your NIC only receives: your traffic + broadcasts
   - Other devices' HTTPS is invisible to you

4. ATTRIBUTION = ANSWERING "WHO DID WHAT"
   - IP 192.168.0.101 + MAC 96:2d:fc:a5:07:ff + SNI icloud.com
   - = "iPhone backed up to iCloud"
   - This is exactly what NetCut's _processTraffic() does

5. BANDWIDTH + SNI = ACTIVITY INFERENCE
   - facebook.com + 5 MB  = feed scrolling
   - fbcdn.net + 50 MB    = video watching
   - googlevideo.com + 300 MB = YouTube streaming
   - reddit.com + 2 MB    = text reading
   - redditmedia.com + 20 MB = image/video viewing

================================================================
LIMITATIONS & LEGAL NOTES
================================================================

LIMITATIONS:
────────────
- Only sees domains (SNI), not full URLs or content
- Modern encryption (ECH, DoH, VPN) hides more
- Randomized MACs make device identification harder
- Without MITM, only YOUR traffic is visible
- ARP scan misses sleeping devices (need TCP SYN wake)

LEGAL/ETHICAL:
──────────────
- Only monitor networks you own or have explicit permission for
- ARP spoofing/MITM is an ATTACK - illegal without authorization
- Employee monitoring requires consent/legal basis
- Personal network: you can monitor your own traffic
- Public WiFi: monitoring others is illegal in most jurisdictions

SAFE LEARNING:
──────────────
- Use isolated lab (VirtualBox host-only network)
- Two VMs: attacker + victim
- Practice ARP spoofing, packet capture, attribution there
- Never test on production networks without written permission
