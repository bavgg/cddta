COMMON SHARED WIFI ATTACK VECTORS (EDUCATIONAL OVERVIEW)
================================================================================

| Attack Category       | Technique                  | What It Does                                    | Detection                                      | Defense                                              |
|----------------------|----------------------------|-------------------------------------------------|------------------------------------------------|------------------------------------------------------|
| MITM                 | ARP Spoofing/Poisoning     | Attacker tricks devices into sending traffic    | `arp -a` shows duplicate MACs; `arpwatch`      | Static ARP; VPN; HTTPS; Port Security; DAI          |
|                      | DNS Spoofing               | Redirects domains to malicious IPs              | Cert warnings; DNSSEC validation               | DoH; DNSSEC; Certificate pinning                    |
|                      | DHCP Spoofing              | Rogue DHCP gives attacker as gateway            | Multiple DHCP offers; `dhcpdump`               | DHCP snooping; 802.1X                               |
| Traffic Interception | Passive Sniffing           | Captures unencrypted traffic (HTTP, FTP, Telnet)| Promiscuous mode (`ifconfig \| grep PROMISC`)  | TLS 1.3; VPN; Encrypted DNS                         |
|                      | SSL Stripping              | Downgrades HTTPS -> HTTP                        | Mixed content warnings; HSTS preload           | HSTS; HTTPS Everywhere; Cert Transparency           |
| Device Targeting     | Evil Twin / Rogue AP       | Fake AP with same SSID, stronger signal         | Multiple APs same SSID; `airport -s`           | WPA3-SAE; Verify AP MAC; WPA3-Enterprise            |
|                      | KRACK                      | Forces nonce reuse in WPA2 handshake            | Rare; patched in modern OS                     | Update firmware/OS; WPA3                            |
|                      | PMKID Attack               | Extracts PMKID for offline cracking             | Hashcat captures; `hcxtools`                   | Long complex PSK; WPA3-Enterprise                   |
| Client-Side          | mDNS/SSDP Enumeration      | Discovers services, hostnames, device types     | `avahi-browse`; `nmap -sU -p 5353`             | Disable mDNS/SSDP; Firewall                         |
|                      | SMB/NetBIOS Relay          | Captures NTLM hashes, relays for auth           | Responder traffic; SMB signing disabled        | SMB signing; Disable NTLM; LLMNR/NetBIOS off        |
| Network Pivoting     | VLAN Hopping               | Double-tagging or switch spoofing               | Unexpected VLAN tags; Switch logs              | Disable DTP; Native VLAN != user VLAN; Port security|
|                      | MAC Flooding               | Overflows switch CAM table -> hub mode          | Port security violations; MAC table full       | Port security; Storm control                        |

YOUR DEFENSE CHECKLIST (FOR SHARED WIFI)
================================================================================

IMMEDIATE (NO ADMIN ACCESS REQUIRED):
-------------------------------------
1. Always use VPN on shared WiFi
2. Verify HTTPS/TLS on all sites
3. Disable auto-connect to open networks
4. Turn off file sharing, AirDrop, mDNS
   sudo defaults write /Library/Preferences/com.apple.NetworkBrowser DisableAirDrop -bool YES

5. Use encrypted DNS (DoH)
   macOS: System Settings -> Network -> DNS -> DNS over HTTPS
   Or: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

6. Check for ARP anomalies
   arp -a | awk '{print $4}' | sort | uniq -d  # Duplicate MACs = possible spoofing

NETWORK ADMIN (IF YOU CONTROL THE ROUTER):
------------------------------------------
[ ] Enable WPA3-SAE (or WPA2-AES minimum)
[ ] Enable 802.11w (Management Frame Protection)
[ ] Enable Client Isolation / AP Isolation
[ ] Disable WPS
[ ] Use strong PSK (20+ chars) or WPA3-Enterprise (RADIUS)
[ ] Enable DHCP Snooping + Dynamic ARP Inspection (managed switches)
[ ] Enable Port Security (sticky MACs, violation=shutdown)
[ ] Disable DTP, CDP, LLDP on user ports
[ ] Separate IoT/Guest VLANs from trusted devices
[ ] Monitor: arpwatch, ntopng, Zeek (Bro), Suricata

DETECT ACTIVE ATTACKS:
----------------------
# ARP spoofing detection
sudo arpwatch -i en0  # Logs MAC-IP changes

# Rogue DHCP detection
sudo dhcpdump -i en0  # Shows all DHCP traffic

# Promiscuous mode check
ifconfig en0 | grep PROMISC  # Should NOT show PROMISC normally

# Wireless scan for evil twins
/System/Library/PrivateFrameworks/Apple80211.framework/Versions/Current/Resources/airport -s | grep -i "your_ssid"

# Certificate transparency check
# Browser: Click lock icon -> Certificate -> Check "Valid" and issuer

QUICK REFERENCE COMMANDS

# Scan for devices (like Netcut)
sudo arp-scan --localnet --interface=en0
sudo nmap -sn 192.168.0.0/24

# Monitor ARP changes continuously
sudo arpwatch -i en0

# Check for promiscuous mode
ifconfig en0 | grep PROMISC

# View ARP table for duplicates
arp -a | awk '{print $4}' | sort | uniq -d

# Wireless scan
/System/Library/PrivateFrameworks/Apple80211.framework/Versions/Current/Resources/airport -s

# DHCP traffic
sudo dhcpdump -i en0

# Passive capture (30 sec)
sudo timeout 30 tcpdump -i en0 -nn -v
